THEME ----- Emerald, kept quiet: deep emerald for headings and table headers, faint emerald tints for zebra rows and totals, near-neutral dark green for body text. The whole palette sits in the CSS variables-by-convention below - change these hex values and every report follows: #065F46 headings, rules, emphasis (emerald 800) #047857 table header background (emerald 700) #D1FAE5 totals fill, strong borders (emerald 100) #ECFDF5 zebra fill, section rows, cards (emerald 50) #1F3A31 body text #5F7A6E muted text CONTEXT AVAILABLE IN EVERY CHILD -------------------------------- report the whole snapshot the JSON endpoint returns institute_name may be empty (superuser with no institute) period_label "First Semester, A.Y. 2025-2026" or a date range program_filter program the report was narrowed to, or empty set_filter student set it was narrowed to, or empty year_level_filter year level it was narrowed to, or empty generated_at datetime, already in local time prepared_by username of whoever asked for the report THE RENDERER HAS OPINIONS ------------------------- xhtml2pdf understands roughly CSS 2.1. That means: * NO flexbox, NO grid, NO CSS variables. Lay things out with tables. * Widths in cm/pt/% behave; viewport units do not exist. * `` and `` are the page counters. * The header/footer frames repeat on every page automatically. The divs they point at are pulled out of the normal flow, which is why they sit at the bottom of this file and still appear at the top of the page. MONEY ----- Written as "PHP 1,234.00" rather than with a peso sign, because the built-in fonts have no U+20B1 glyph and it would print as a blank box.
